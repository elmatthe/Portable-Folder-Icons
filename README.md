# Portable Folder Icons

Portable Folder Icons is a Windows 10/11 current-user tool for assigning
custom icons to folders from Explorer's classic **Show more options** menu.

Version 0.1.0 is currently under implementation. The completed setup will use
only inbox Windows PowerShell and built-in Windows APIs—no administrator
rights, Python, package download, network access, or Explorer restart.
